# 紫微斗数 ZIWEI DOUSHU · 项目说明

> 2026 Qoder 高校创造力大赛 · LifeHack（生活娱乐）赛道参赛作品
> 一句话定位：**把一千年的星象学，转成你指尖的罗盘**——一个打开即玩、算在本地、带走可分享的紫微斗数交互星盘。

---

## 一、项目类型

| 维度 | 说明 |
| --- | --- |
| 产品形态 | 单页交互式 Web 应用（文化娱乐体验站），非表单工具、非内容资讯站 |
| 技术形态 | **纯静态前端作品**：Vite + 原生 TypeScript（无框架、无 UI 库），构建产物 `dist/` 完全自包含 |
| 计算形态 | **浏览器端排盘引擎**：安星、排盘、四化、格局、大限全部本地计算，零常驻服务端、零生辰上传 |
| 架构形态 | 单一状态源（pub/sub store）+ 可插拔数据访问层：未接后端时自动本地回落，接口契约统一 `/api/v1`（见 `docs/api.md`） |
| 部署形态 | 适配 Qoder Sites 免费版静态托管，亦可任意静态服务器 / CDN 直接托管 |
| 赛道归属 | LifeHack（生活娱乐）：以传统命理的**娱乐化、人格化、可分享**体验为核心，而非迷信决策工具 |

## 二、项目作用

### 2.1 解决什么

传统排盘工具普遍是"表单 + 表格"的专业门槛形态：看不懂、不好玩、带不走。紫微斗数把紫微斗数重构为一条**普通人三分钟能走完的娱乐体验链**：

```
输入生辰八字与出生地 → 即时点亮十二宫星象罗盘 → 点击宫位/星曜探索解读
→ 播放十二段大限"人生剧本"推演 → 生成人格化星卡下载分享
```

### 2.2 提供什么

- **专业口径，娱乐表达**：真太阳时（经度差 + 均时差）、中国 1986–1991 夏令时、闰月十五分界、晚子时来日/当日、立春/正月初一年分界五种口径可选，校正明细透明可查；解读文案全部原创娱乐化表述，附"仅供文化体验"免责边界。
- **可交互的视觉主体**：可拖拽旋转的星象罗盘（四化飞星轨迹动画、三方四正连线、宫位聚焦景深、72 刻度外环），一键切换传统方盘；12 件常驻控制台工具实时调节旋转、星曜大小、光晕、图层与景深。
- **差异化玩法**：十二段大限人生时间轴推演（可播放、可跳转、可联动罗盘定位）+ 1080×1440 人格化星卡（原型标题、诗句、五维雷达、命盘摘要，署名即时重绘、PNG 导出、判词复制）。
- **知识普及层**：20 条经典格局判定、单星与宫位解读抽屉、公有领域古籍引文轮播，让娱乐体验同时成为传统文化入口。
- **隐私友好**：生辰数据默认只存浏览器 localStorage（最近 24 盘历史），不注册、不上传。

### 2.3 面向谁

对星座/命理/国风文化好奇的年轻用户、想给朋友圈做一张"人格星卡"的分享者、以及需要低门槛接触紫微斗数知识结构的初学者。

## 三、参加比赛的点（评审视角）

### 3.1 赛道契合：生活娱乐的"玩"与"分享"闭环

LifeHack 赛道评判的是生活场景里的趣味与可用性。本作不做算命生意，做**文化玩具**：人生阶段推演是"玩自己的剧本"，星卡是"带走自己的角色卡"——娱乐属性第一眼可感知，且主流程终点天然落在社交分享上。

### 3.2 第一眼差异化：不是又一个排盘表格

- 首页即**海报廊**：编辑刊头（巨字衬线标题 + 十四主星伙伴行 + 古籍轮播）之下，六张原创奶金国风工笔插画海报竖排成廊，每张是一个功能入口；固定透明页头滚动转纸白，全屏白菜单以巨型编号链接展开，桌面左侧常驻竖轨 scrollspy。
- 命盘即**可旋转罗盘**：纸白底色上朱砂主星、紫微吉星、黛蓝煞星分层排布，四化飞星以流动弧线动画呈现，选中宫位时其余星曜淡出形成景深——东方罗盘意象与纸墨编辑排版在同一套设计语言中融合；命盘区为左盘右栏的 split workspace，视图 pill 一键切换传统方盘。
- 专属配色体系：纸白 `#ffffff` / 米灰 `#f5f5f5` 承载大面积背景，奶金 `#f7f1e3` 海报与中央 tile 渐变，朱砂 `#a83228`、紫微 `#6e3da5`、黛蓝 `#1a56a8`、鎏金 `#c8a03a`、青绿 `#2d7a4a` 为强调；四化禄绿 / 权蓝 / 科赭 / 忌朱砂方形印章；墨色文字五级分层，全站无默认灰。
- 分层氛围：纸金浮尘 Canvas、纸白 mesh 渐变、噪点肌理、分级入场序列、滚动揭示、合成音效（绑定可见事件、默认开启、顶部一键静音）。

### 3.3 完整度：没有半成品，主流程实测走通

- 打开即有真实示例盘与全部真实内容，无 TODO / 占位文案 / 假按钮。
- **62 项双视口 E2E 断言全通过**（1440×900 桌面 / 390×844 移动，puppeteer 驱动真实浏览器）：渲染、控件、抽屉、拖拽旋转、视图往返、错误态、重复排盘稳定性、PNG 导出、复制判词、锚点与静音、零水平溢出、**控制台零错误**。
- **17 项引擎 smoke 断言全通过**：十二宫/四化/大限不变量、命盘 ID 确定性、五类错误码、口径开关真实生效。
- hover / 选中 / 加载 / 空态 / 错误态齐全；`prefers-reduced-motion` 与无 IntersectionObserver 环境优雅降级。

### 3.4 技术含金量：简单可靠选型下的硬功夫

- **浏览器端排盘**：以 MIT 许可 iztro 为内核做归一化封装（宫索引寅起、星曜分类、亮度、四化统一模型），叠加自研历法校正层（均时差天文近似式、夏令时区间表、跨日进位），五种口径组合均正确作用。
- **确定性设计**：命盘 ID 由输入 + 口径哈希生成，同输入同盘；五维指标为确定性趣味算法——可缓存、可分享、可复现，接口幂等语义由此而来。
- **可插拔后端**：统一数据访问层 + 统一 `/api/v1` 契约文档（共享模型与前端类型唯一来源一致，响应示例由真实引擎生成），8 秒超时自动回落本地——纯静态部署不牺牲未来扩展性。
- **工程克制**：运行时依赖仅 2 个（iztro、lunar-javascript），构建产物 gzip 后 JS ≈ 301 kB、CSS ≈ 10.2 kB；Node 16 即可构建，评审复跑零门槛。

### 3.5 文化价值与合规边界

- 传统文化（紫微斗数 / 倪海厦《天纪》知识体系）的**数字化娱乐转译**：古籍原文取公有领域短句，解读、格局判词、大限叙事、星卡诗句全部原创。
- 复用边界清晰：仅参考 MIT 算法与公有领域文本，**未使用**参考仓库的 CC BY-NC-SA 内容、未开源断语库、AI prompt 与后端接口；界面与产品形态完全原创，README 与 LICENSE 逐项署名。
- 娱乐化免责贯穿全站（抽屉页脚、星卡页脚、关于页），价值导向稳妥。

### 3.6 部署与演示友好

- `npm run build` 产出纯静态 `dist/`，Qoder Sites 免费静态托管一键公开（IDE「站点」或 CLI `/sites`），现场演示可直接给公网链接。
- 仓库自带三级验证命令：`typecheck` / `test:engine` / `test:ui`，评审可复跑全部实测结论。
